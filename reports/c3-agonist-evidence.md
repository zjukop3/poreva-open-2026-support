# C3（GLP1R）激动剂功能验证三路线 —— 证据报告

**运行**：`runs/c3-agonist-validation/`
**日期**：2026-10-23
**性质**：**全部为计算/结构证据。没有任何功能实验。本报告不含"证明是激动剂"的结论，也不可能含。**

---

## 0. 一句话结论（先说最不讨喜的）

三条路线里跑通两条（R1 构象足迹、R2 界面重叠），第三条（R3 文献/结构）完成证据汇编。

**结论是负面的，必须正面写出来：**

> **24 条定稿设计中 17 条在显式三元复合物建模中与天然 GLP-1 肽发生立体冲突（结合物占用了
> 肽本身的位置）—— 这 17 条按机制讲更可能是竞争性阻断剂，不是激动剂。**
> **剩下 7 条做到了"无冲突共存"，但其中 6 条仍然占据天然肽 N 端激活段的受体子位点
> （占据率 0.17–1.00）。**
> **只有 1 条（`core35_70c_0_model_0_d1`）同时具备"无冲突共存 + N 端激活子位点 0.00 占据率
> + 高 Jaccard(0.514) + 高 pDockQ2(0.667)"。**

**并且这条也不构成激动剂证据** —— 见 §6 的判据讨论：C3 的构造（GLP1R 29–170）
**根本不含跨膜域**，而激活步骤就发生在跨膜域。**本方案用现有构造无法验证激动活性。**

---

## 1. 为什么必须做这件事

C3 是三个挑战里**唯一要求功能**的（必须是激动剂）。而我们的全部既有指标
——`pDockQ2`（界面质量）、`Jaccard`（足迹重合）——**测的都是结合，不是激活**。
这是 C3 最大、也是最容易被评委指出的软肋。

三条路线各自的定位：

| 路线 | 能回答什么 | 不能回答什么 |
|---|---|---|
| **R1 构象足迹** | 结合物是否**允许**天然肽共存、受体 ECD 构象是否被破坏 | 是否触发激活 |
| **R2 界面重叠** | 结合位点与天然激动剂位点的**空间关系**（抬高/阻断/让位） | 是否触发激活 |
| **R3 文献/结构** | 已知机制下这类结合模式**属于哪一类** | 本设计是否属于该类 |

## 2. R1 构象足迹路线

### 2.1 做法

对 24 条定稿设计各建一个 **四链三元复合物**：`结合物(A) + GLP1R 构造(B,C) + 天然 GLP-1(7-37)(P)`，
Boltz-2，参数与既有打分完全一致（`recycling 3 / sampling 200 / diffusion_samples 3 / seed 20261042`）。
另加一个**无结合物对照**（受体 + 肽），作为"没人抢的时候肽怎么结合"的基准。

| 对象 | 值 |
|---|---|
| 受体构造 | GLP1R 29–170（B = 29–129，C = 130–170，与设计条件同源） |
| 天然肽 | GLP-1(7-37)，取自 5VAI 实验构象：`HAEGTFTSDVSSYLEGQAAKEFIAWLVKGRG` |
| 作业数 | 24 三元 + 1 对照 = 25，全部成功（75 个扩散样本） |

### 2.2 立体冲突判定（比单点距离更稳的判据）

用**重原子对数**而不是最小距离单值：把结合物与肽之间 **< 3.2 Å** 的重原子对记为冲突
（3.2 Å 对 C–C 已经意味着范德华面重叠，判据偏宽松）。

```
coexist-clash-free := 3 个扩散样本中至少 1 个样本里，结合物-肽 < 3.2 Å 的重原子对为 0
```

### 2.3 结果

| | 条数 |
|---|---|
| **coexist-clash-free（能与肽共存）** | **7** |
| **peptide-competitive（三个样本全部冲突）** | **17** |

| | coexist 组 | competitive 组 |
|---|---|---|
| 提交 pDockQ2 中位 | 0.604 | 0.5394 |
| 天然位点占据率（occN）中位 | — | — |
| 全体 occN 中位 | **0.444** | |
| 全体 N 端子位点占据率中位 | **0.414** | |

> **高分不挑边**：pDockQ2 最高的两条（0.789、0.745）**都是** peptide-competitive。
> coexist 组的中位 pDockQ2 只比 competitive 组高 0.065。
> **"我们的设计打分高所以是好激动剂"这个推论在数据上不成立。**

### 2.5 ⚠️ N 端子位点这件事的**方法学限制**（必须写进材料）

天然肽的 N 端激活段（GLP-1 7–14）在我们的构造里**几乎无处可去**：

| 参考结构 | 该段接触的受体残基总数 | 其中落在 29–170 构造内的 |
|---|---|---|
| 5VAI GLP-1(7-37) | 21 | **1**（145） |
| 6X18 GLP-1(7-36) | 27 | **5**（141,144,145,148,152） |
| 6B3J exendin-P5 | 9 | 3（137,138,141） |

**该段接触的受体残基有 21–27 个，其中 20–27 个在跨膜域/结构域外——而我们的构造里没有它们。**

> **因此"N 端子位点占据率 0.00"这个数字的信息量有限**：它只覆盖了 5 个残基，
> **不能**据此声称"设计不会阻断 N 端插入"。
> 它是**局部**证据，不是全局证据。**这条限制在材料里必须与数字同时出现。**

### 2.6 受体 ECD 构象（R1 的另一半）

先用**实验噪声作尺子**：三个独立激动剂复合物（5VAI / 6X18 / 6B3J）在
共同 133 个 CA 上的两两 RMSD（Kabsch 叠加后）：

| 配对 | CA-RMSD |
|---|---|
| 5VAI vs 6B3J | 2.047 Å |
| 5VAI vs 6X18 | 2.141 Å |
| 6B3J vs 6X18 | 1.997 Å |

**逐残基偏差**（5VAI vs 6B3J，叠加后）：均值 1.612 Å，最大 **6.618 Å（残基 147）**。

> **判读规则**：ECD 的 CA-RMSD 在 **≈2 Å 以内**不能被称作"构象改变"，
> 因为不同的实验激动剂复合物之间就有 2 Å 的差别。残基 147 是实验数据本身就差异最大的位置。
> **注意**：这个尺子覆盖的是整个可对齐 ECD（133 残基），比我们构造的 29–170 更宽，
> 所以它是**保守（偏宽）**的噪声估计。

### 3.1 已有的数字（本次未重算，用于对齐口径）

| 口径 | 值 |
|---|---|
| 定稿 24 条 Jaccard | 中位 **0.2936**，均值 **0.3347**，范围 0.1562 – 0.5429 |
| 定稿 24 条 coverage（天然足迹被命中的比例） | 中位 **0.500**，最大 **0.833** |

| 全部 144 条设计池 Jaccard | 中位 0.2195，均值 0.2355，最大 0.6129 |

> ⚠️ 口径澄清：`Jaccard 0.462 / footprint 75%` 是**单条最佳**（`foot_loose_110c_d2`）的数字，
> **不是 24 条的中位数**。材料里若把单条最佳写成集合水平，会被抓。
> 24 条集合水平应写 **Jaccard 中位 0.29 / 均值 0.33 / coverage 中位 0.50 / 最大 0.83**。

### 3.2 把重叠度放到一个刻度上：随机零模型

"设计会不会随便粘到某个凹槽上"这个替代解释必须排除。做法：对每条设计，
从**实际被建模的受体表面**上随机取"与该设计相同数量的接触残基"，看能命中天然足迹多少。

| | 命中天然足迹的比例 |
|---|---|
| 随机零模型 均值 | **0.2125** |
| 随机零模型 95 分位 | **0.4167** |
| 全部 144 条设计 均值 | **0.415** |
| 全部 144 条设计 最大 | **0.958** |

**判读（诚实版）**：
- **设计组的均值（0.415）刚好落在零模型的 95 分位上** —— 说明**整个设计库对天然凹槽只有
  温和的富集倾向**，不足以称为"选择性识别该位点"；
- **但单条最大 0.958 远超零模型分布** —— 说明**存在真正偏向该凹槽的个体**；
- **结论**：**"我们的设计普遍靶向天然激动剂位点"这个说法，数据不支持。
  能支持的是"其中一部分设计明显偏向该位点"。**

### 3.3 N 端 / C 端子位点的分离

天然 GLP-1 的受体接触在机制上分两段：

| 子位点 | GLP-1 残基 | 作用 | 构造内可见的受体残基 |
|---|---|---|---|
| **N 端段** | 7–14 | 插入受体核心 → **触发激活** | 5（141,144,145,148,152） |
| **C 端段** | 15–37 | 停靠 ECD 凹槽 | 20（6X18 口径） |

**判别逻辑**：
- **只占 C 端段 = 可能保留肽的 N 端插入路径** → 免疫于"纯阻断剂"的批评（但也**不等于激动**）；
- **占 N 端段 = 按机制即为阻断剂**。

24 条定稿落在两段的占据率（逐条见 `c3-r1-verdict.tsv`）：中位 N 端 **0.414**、中位 C 端 **0.426**。

### 3.4 与 R1 的交叉验证（两者独立，结论一致）

R1（三元冲突）与 R2（界面重叠）用的是**不同的模拟与不同的判据**，但指向同一结论：

- R2 说设计平均只温和偏向天然凹槽；
- R1 说大部分设计（17/24）在显式三元复合物里与肽**冲突**。

**两者不矛盾**：一个设计可以"比较偏向该凹槽"（R2 中高）**并且**"粘上去就把肽挤掉"（R1 冲突）。
**真正互斥的是"占位"与"共存"**，而 R1 直接测的正是这一点。

## 4. R3 文献/结构证据路线

> `web_search` 在本会话不可用（API 配额），**改由 Europe PMC REST API 检索**，
> 每条结论配 PMID/DOI，原始检索结果存 `literature.json`（含摘要原文）。

### 4.1 GLP-1R 激活的**两域（two-domain）机制**

- GLP-1R 是 **class B1 GPCR**：大胞外域（ECD）+ 七次跨膜域（TMD）。
  **所有 class B1 受体在近 5 年内均已获得与 G 蛋白复合的 cryo-EM 结构**
  （PMID 36546772, *Endocrine Reviews* 2023, doi:10.1210/endrev/bnac033）。
- **两域结合机制是 GLP-1 与其受体的公认模型**：肽的 C 端段与 ECD 结合、
  N 端段与 TMD/核心区作用完成激活
  （PMID 27630114, *Pharmacological Reviews* 2016, doi:10.1124/pr.115.011395）。
- GLP-1R 的**肽激动剂结合动力学与 G 蛋白激活动力学相关**
  （PMID 35013280, *Nature Communications* 2022, doi:10.1038/s41467-021-27760-0）——
  即"怎么结合"与"激活多快"是耦合的，支持"N 端段接触模式决定激活"。
- 综述性总结见 PMID 40629042（*Exp Mol Med* 2025, doi:10.1038/s12276-025-01497-y），
  其中以 GLP-1R 为案例说明结构信息如何导向药物设计。

**对本项目的意义**：激活**不是**"结合在 ECD 上"这么简单，而是**肽 N 端段与受体核心的
一次接触事件**。我们的构造（29–170）**不含该核心区**。

### 4.2 各激动剂类别的结构特征

| 类别 | 代表 | 结合位置 | 是否依赖 ECD | 来源 |
|---|---|---|---|---|
| 肽类激动剂 | GLP-1, exendin-4, semaglutide | C 端段→ECD，N 端段→核心 | **是** | PMID 27630114；PMID 40629042 |
| 小分子/非肽激动剂 | danuglipron (PF-06882961), orforglipron (LY3502970), TT-OAD2 | TMD 口袋（TM1/TM2/TM7 附近） | 报道称可不依赖 ECD 完整功能 | 综述 PMID 42729683、PMID 36546772（**具体 TM 残基归属标记为"需核验"**） |
| 正别构调节剂 (PAM) | BETP 及 6P6T/7LCJ 系列结构中的 PAM | TMD 内别构口袋，**增强**天然肽作用 | 需要肽存在 | PMID 36546772；PMID 39771585 |
| 激动型抗体 | — | 报道通过稳定活化态受体二聚体/构象 | 机制与配体不同 | 检索命中以综述为主（PMID 42225334 等），**具体机制标记为"需核验"** |

> ⚠️ **上表中标注"需核验"的格子**：Europe PMC 检索返回的是综述而非一手结构论文，
> 本报告**不主张**具体的 TM 残基编号或小分子接触图。
> 需要精确到残基时，应直接查对应 PDB 条目的配体-受体接触表。

### 4.3 ECD-only 结合能否激活？—— **现有证据不支持**

这是本路线要回答的核心问题，回答是：

> **在检索到的文献中，未发现"配体只结合 ECD 肽凹槽、不接触 TMD、却能激活 class B GPCR"
> 的确证先例。**
> 已知的肽类激动剂**全部**依赖 N 端段与核心区的作用；
> 已知的非肽激动剂**全部**结合 TMD 或 ECD–TMD 界面。
> 天然拮抗剂 exendin(9-39) 恰恰是**缺少** N 端段的那一类 —— 这个模式在文献里被反复引用
> （PMID 27630114）。

**因此对本项目的直接推论（必须写进材料）**：

> 我们的设计**只结合 ECD 肽凹槽**，这一结合模式在已知机制里**对应的是"停靠"而不是"激活"**。
> **没有机制依据支持"ECD-only 结合 → 激动"这一推论。**

### 4.4 设计时可用的结构判据（可用于自我评估）

综合文献机制，对"可能具备激动潜力"的 binder，可用的**结构性必要条件**（注意：是必要条件，不是充分条件）：

1. **不阻断肽 N 端段与核心区的接触路径**（最小条件：不占据 N 端子位点与其延伸路径）；
2. **不把 ECD 锁在非活性构象**（ECD 与 TMD 的相对取向是关键自由度）；
3. **不阻断 ECD–TMD 的相对运动**（任何跨这两个结构域的加固都值得警惕）；
4. **保留 TM 核心的可及性**（至少不覆盖其入口）；
5. 或者**转换设计目标**：做成**明确的 PAM**（结合 TMD 别构口袋、需要肽存在），
   而不是硬做"激动剂"。

**按这 5 条检视我们的设计**：
- 第 1 条：**17/24 直接违反**（peptide-competitive）；6/7 条 coexist 者仍占据 N 端子位点
  （该子位点在我们的构造里只有 5 个残基，所以这条的判定**不完整**）；
- 第 2–5 条：**无法评估** —— 因为设计条件里**根本没有跨膜域**。

## 6. 结构证据 vs 功能证据 —— 边界必须画清

### 6.1 本报告**能**主张的（结构证据）

1. 设计**结合**在 GLP1R ECD 肽凹槽（pDockQ2 中位 0.5883，Jaccard 中位 0.2936）；
2. 在显式三元复合物里，**17/24 的设计与天然 GLP-1 发生立体冲突**；
3. 设计库整体对天然凹槽的偏向**只是温和的**（与随机零模型对比）；
4. 已知的 class B GPCR 激动机制**要求**配体接触受体核心区，而**本设计完全没有这一段**。

### 6.2 本报告**不能**主张的（功能证据）

1. ❌ **不能说任何一条是激动剂**；
2. ❌ 不能说"Jaccard 高所以会激活" —— Jaccard 与激活之间**没有任何已建立的定量关系**；
3. ❌ 不能说"pDockQ2 高所以会激活" —— pDockQ2 是界面质量代理，与激活正交；
4. ❌ 不能说"不占 N 端子位点所以会激活" —— 该子位点在我们的构造里只覆盖 5 个残基；
5. ❌ 不能说"设计会阻断"（严格意义上）—— 冲突来自计算模型，不是实验；
   正确表述是"**模型中表现为冲突，因此按机制更可能是阻断剂**"。

### 6.3 **"无功能实验无法确证激动活性"这一限制的标准表述**

> 本挑战的 C3 要求功能性（激动剂），而本项目**没有任何功能实验数据**
> （无 cAMP / GLP-1 分泌 / β-arrestin 招募 / 受体构象报告探针）。
> `pDockQ2` 与足迹 `Jaccard` 都是**结合质量**的结构代理，
> **与"是否激活"没有已建立的定量映射**。
> 本次新增的构象足迹三元建模进一步表明，多数设计在结构上**与激动机制不相容**。
> **因此本方对 C3 的激动活性不作任何主张**；
> 若要确证，唯一路径是湿实验（cAMP 剂量-反应 + 至少一个正交读出）。

## 9. 局限（完整清单）

1. **构造截断（最根本）**：GLP1R 29–170 **不含跨膜域**，而激活发生在跨膜域。
   **本套验证在原理上无法验证激动活性。** 这不是方法缺陷，是设计条件决定的边界。
2. **N 端子位点覆盖不全**：该子位点在构造内仅 5 残基（完整为 21–27），
   因此"N 端子位点占据率"的信息量有限。
3. **ECD 构象尺子偏宽**：2.0–2.1 Å 的噪声来自整个可对齐 ECD（133 残基）而非我们的构造，
   属保守估计；同时也意味着**我们无法分辨 1 Å 量级的构象差异**。
4. **无对照结合物**：没有"已知激动剂/已知拮抗剂"在我们的构造里跑同一套三元模型，
   因此**无法用本构造校准"coexist 判据"的灵敏度**。
5. **Boltz-2 在四链、单序列、无 MSA 条件下的三元预测精度未经实验校验**；
   冲突判定依赖其侧链摆位。
6. **统计效力**：24 条设计、每条 3 样本；§2.4 的"唯一一条"结论
   **样本量为 1**，不应作为强主张。
7. **R3 依赖二手来源**：多数机制陈述来自综述而非一手结构论文；
   `web_search` 不可用导致检索广度受限，标为"需核验"的格子必须在材料里保留该标记。
8. **全部为计算预测，无任何实验验证。**
